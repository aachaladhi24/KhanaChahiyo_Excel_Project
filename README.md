# KhanaChahiyo Excel Data Analysis

## About the Project

This project analyzes KhanaChahiyo food delivery data using Microsoft Excel. The analysis focuses on sales performance, customer ratings, cancellations, city performance, and monthly revenue.

## Tools Used

* Microsoft Excel
* Excel formulas
* Pivot Tables
* Charts and Dashboard
* Goal Seek

## Key Analysis

The project looks at:

* Total revenue and monthly revenue
* Number of orders
* Customer ratings
* Cancellation rate
* Revenue by city
* Monthly performance
* Target achievement
* Order requirement using Goal Seek

## Key Findings

* Total revenue was **Rs. 176,407**.
* The revenue target of **Rs. 150,000** was achieved.
* **Kathmandu** generated the highest revenue at **Rs. 43,286**.
* **October 2025** had the highest monthly revenue at **Rs. 50,629**.
* The overall customer rating was **4.09**.
* The cancellation rate was **1%**, which was below the 8% target.
* Goal Seek showed that around **65 orders per month** were needed to reach a Rs. 35,000 monthly revenue target.
